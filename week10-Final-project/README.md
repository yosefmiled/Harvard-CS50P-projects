# Explore Africa
#### Video Demo: < >
#### Description: Explore Africa is an AI-powered terminal app that allows users to explore the African continent and its 54 nations in a fun way. You can choose any African country of your choice and then learn about its history, food, languages, and more.

As I was scrolling through TikTok I noticed the huge amount of people that know nothing about Africa, this huge continent where humankind first appeared, the most resource-rich continent with the most beautiful sites that your eyes could ever witness. Africa itself has more than 2000 languages, that is why I dedicated a whole category for languages. Personally I think that Africa holds a lot of hidden gems that the world has yet to see, and I always say "if you have never visited an African country before then you still have not seen beauty". You can sense Africa's beauty and hospitality in its people, who will make you feel at home regardless of your beliefs.

When you first start this program you will see a table that contains all 54 African nations sorted alphabetically and numbered from 1 to 54. You start by picking the country of your choice and entering its number. Another table appears that contains four options other than quitting the program and going back: History, Food and Recipes, Languages and Dialects, and Famous People and Athletes. Once you have chosen the category that you want to explore in the selected country you get more options. For example if you choose to learn about the languages and dialects of Tunisia you can either learn about the official languages, the regional dialects, or common phrases to learn. The program then sends a request to Google Gemini and displays an AI-generated response.

This project contains four files. The main file project.py contains the main code of the program. It has a main() function that controls all the navigation, a get_african_countries() function that returns the list of all 54 countries, a validate() function that checks if the user's input is valid, a prompt() function that builds the question sent to the AI based on the country, category and subcategory selected, a format_response() function that cleans the AI response before displaying it, an ai_response() function that sends the prompt to Gemini and returns the text, a display_country_table() function that renders the countries table, and a display_menu() function that renders any numbered menu. The testing file test_project.py contains all the tests I wrote to test my functions using pytest. The requirements.txt file contains every pip-installable library used in this program, which allows others to install the dependencies and run it. Finally README.md is this file, in which I am describing my project.

In this project I made some decisions that I think are worth mentioning. First I decided to use the Gemini AI API over others because it is free, easy to use, and powerful enough to generate rich cultural content. Second I decided to make this a terminal app because the rich library makes the terminal look impressive without needing any HTML or CSS, and it keeps the focus on Python logic. Third, I defined each category as its own variable before combining them all into the CATEGORIES dictionary — this makes the code much easier to read and edit. Finally I noticed early on that I was repeating the same table design everywhere and using input validation in multiple places, so I created a dedicated function for each, display_menu() to handle all menus and validate() to handle all input checking, which made the code much simpler and cleaner.
